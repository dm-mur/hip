# Health Intelligence Platform (HIP)

An open-source, AI-ready health analytics platform for ingesting, transforming, validating, and analyzing health data from systems such as DHIS2 and EMRs.

## Features

- Docker-first architecture
- PostgreSQL data warehouse
- Flyway database versioning
- Bronze, Silver, Gold architecture
- Metadata-driven ingestion
- AI-ready design

## Technology Stack

- PostgreSQL
- Docker
- Flyway
- Python
- Airflow (planned)
- dbt (planned)
